# UziPet 0.14.7

Узи живёт на рабочем столе: ходит по нижнему краю экрана и по верхним кромкам окон,
прыгает между окнами, сидит, свесив ноги, засыпает, если долго ничего не трогать,
и иногда утаскивает иконку с рабочего стола.

> **Внимание.** Проект изначально делался для личного пользования, а не как готовый продукт для всех.
> Код и большая часть текстов написаны с помощью ИИ (Claude), так что где-то он может быть неаккуратным,
> а что-то работает только на конкретном компьютере автора.
>
> Это фанатская штука: Узи Дорман и весь мир Murder Drones принадлежат Glitch Productions.

## Запуск

Сборка: `build.bat` (MSVC, C++20), exe в `bin\UziPet.exe`. Выпуск одним файлом: `python tools/release.py "что нового"` → `dist\UziPet-<версия>.exe`.
Значок в трее: клик открывает настройки, правый клик — «Настройки…» и «Выключить Узи».
Чтобы обновить Узи, перетащите EXE более новой версии на персонажа и подтвердите установку в облачке.
На компьютере без UziPet достаточно запустить EXE.

## Моды на Python

Мод **Таймер** находится в `mods_for_UziPet/timer`. Скопируйте папку `timer` в папку модов и включите
его в настройках. Затем нажмите ПКМ по Узи и выберите часы. В облачке можно настроить
или заменить отсчёт. Когда время выйдет, нажмите на Узи и выберите
**Успокоить(Выключить таймер)**.

Для изменения реплик и звука откройте установленную папку `timer`. Реплики лежат в
`phrases.json`. Можно заменить `timer.wav` или добавить `timer.mp3` либо `timer.ogg`.
Для MP3 и OGG нужен `ffplay.exe` в `PATH`. Перезапустите мод после правок.

Откройте **Настройки → Моды… → Открыть папку модов**. Поместите каждый мод в отдельную папку внутри
`%APPDATA%\UziPet\mods`, нажмите **Обновить список**, выберите мод и нажмите **Включить**.
Выбор сохраняется между запусками. Выключение сразу останавливает процесс мода. Чтобы применить
изменения в скрипте, выключите и снова включите мод.

EXE для Windows x64 включает компактный Python со стандартной библиотекой. UziPet распаковывает его
рядом с приложением при установке или обновлении. Таймер устанавливается отдельной папкой как обычный мод.
Мод из пользовательской папки запускается после явного включения. Скрипт выполняется с
правами текущего пользователя, поэтому включайте только моды из источников, которым доверяете.

Создайте, например, папку `hello-uzi` с двумя файлами UTF-8.

`manifest.json`

```json
{"id": "hello-uzi", "name": "Привет, Узи", "version": "1.0.0", "api": 1}
```

`main.py`

```python
import uzipet

hello_on_click = False


def on_event(event):
    global hello_on_click
    if event["type"] == "start":
        uzipet.button("greet", "Поздороваться")
        uzipet.toggle("on-click", "Здороваться по клику")
    elif event["type"] == "control" and event["id"] == "greet":
        uzipet.say("Привет из Python!")
    elif event["type"] == "control" and event["id"] == "on-click":
        hello_on_click = event["value"]
    elif event["type"] == "click" and hello_on_click:
        uzipet.say("Привет!")
```

Кнопки и переключатели появляются под выбранным модом (до четырёх элементов). В событии
`control` поле `value` содержит новое состояние переключателя или `None` для кнопки.
Значения переключателей действуют до остановки мода. В `id` мода и элементов управления
допустимы строчные латинские буквы, цифры, дефис и подчёркивание. ID мода должен быть уникальным.
Ошибки запуска и обработчиков отображаются в окне модов.

### Интерфейс и поведение питомца

- `uzipet.pet_menu(id, label, icon="")` добавляет пункт в меню по ПКМ. Значок — имя SVG или
  PNG в корне мода. При выборе приходит событие `{"type": "pet_menu", "id": ...}`.
- `uzipet.show_dialog(id, text, buttons, fields=(), status="", cancel="")` показывает облачко.
  Кнопки задаются словарями `{"id": ..., "label": ...}`, поля — словарями
  `{"id": ..., "label": ..., "value": ..., "type": "text" или "integer", "length": ...}`.
  Поддерживается до четырёх кнопок и четырёх полей. При ответе приходит событие
  `{"type": "dialog", "id": ..., "button": ..., "fields": {...}}`. Значения полей — строки.
  Escape выбирает кнопку `cancel`, если она указана. При закрытии без ответа `button` равен `None`.
- `uzipet.update_dialog(id, status=...)` обновляет строку состояния, сохраняя введённые значения.
  `uzipet.close_dialog(id)` закрывает облачко этого мода.
- `uzipet.pace(speed=0, across_monitors=False)` запускает ходьбу туда-обратно с указанным
  множителем скорости. Значение `0` завершает ходьбу. При отключении мода управление возвращается Узи.
- `uzipet.capture_clicks(True)` направляет клики по Узи в обработчик мода в виде события
  `{"type": "click"}`. `capture_clicks(False)` возвращает обычную реакцию на клик.
- Событие `{"type": "relationship", "tier": ...}` сообщает текущий уровень отношений от 0 до 3
  после запуска мода и при изменении уровня.

## Что с ней можно делать

- гладить: поводить курсором по голове туда-сюда, без нажатия;
- тыкать: клик по ней;
- подкинуть: двойной клик;
- взять и бросить: зажать и потащить, отпустить на ходу; за руку она идёт следом, за ногу висит вниз головой;
- дать файл: перетащить его прямо на неё (файл никуда не копируется, она только смотрит на имя и иконку);
- двигать окно, на котором она стоит (сильно трясти не стоит).

## Что она замечает сама

- громкий звук: жмурится и закрывает уши (на фоновую музыку не танцует);
- скриншот: спрашивает, хорошо ли получилась;
- полтора часа без перерыва: потягивается и зовёт размяться;
- смену приложения: иногда комментирует (Blender, Unreal, код, Discord, Claude, диспетчер задач);
- игру, Blender или кино на весь экран: садится на панель задач и смотрит, при двух мониторах уходит на свободный;
- второй монитор: иногда прыгает туда сама, а если не допрыгнуть, просит перенести;
- прячется за верхним краем окна и выглядывает;
- залезает в папки на рабочем столе; если открыть эту папку в проводнике, вылезает оттуда «Эй, я занята!»
  и закрывает окно (выключается в трее);
- мало места на диске или полная корзина: предлагает поискать мусор. Удаляет только после «Удаляй»:
  временные файлы старше суток и корзину (через окно подтверждения Windows). Толстые папки только называет;
- много кликов в одно место: «А можно я попробую?». Возьми её и поднеси к кнопке: она тянется к ней рукой, сгибая локоть.
  Дотянулась — говорит «Отпускай!», после этого держится за кнопку, нажимает и хлопает в ладоши.

Вопросы она задаёт облачком с кнопками. Если не отвечать, вопрос уходит сам.

## Браузер

Когда ты сидишь в браузере, она иногда просится «кое-что посмотреть». Можно и самому: «Сходи в браузер» в трее.

С расширением (папка `bin\extension`) у неё своя фоновая вкладка в твоём браузере: она печатает запрос в Google
(безопасный поиск), открывает найденное только с проверенных сайтов (Википедия, Stack Overflow, Хабр, Fandom,
научные сайты, фотостоки), листает и иногда ищет дальше по заголовку с прочитанной страницы. Её страницы
удаляются из истории браузера (вместе с твоими заходами на те же адреса). Откроешь её вкладку: она стоит прямо
на заголовках и картинках, листает и жмёт на результаты.

Смущается по-разному: техника и наука ничего, котики и милое слегка, личное (её «поисковые запросы» про Н)
очень. Если застать её на личном, кричит, краснеет, закрывает вкладку и прячется в папку. Личное
выключается пунктом «Смущающие страницы в браузере».

Установка расширения: «Подключить расширение для браузера…» в трее, дальше по подсказке
(chrome://extensions, режим разработчика, «Загрузить распакованное», папка `bin\extension`).
Расширение говорит только с Узи на 127.0.0.1:47731 и подписывает запросы секретом из `token.json`,
который Узи пишет при каждом запуске.

Без расширения она открывает свою страницу (Википедия, Stack Overflow, котики, дневник) отдельной вкладкой.

## Сборка

`build.bat` (MSVC из Visual Studio 18). Для упаковки нужны Python и официальный компактный пакет
CPython для Windows x64. Скрипт скачивает его с python.org при первой сборке, проверяет SHA-256
и кеширует архив в `obj`. Приложение использует Win32, Direct2D, DirectWrite и WIC.

Отладочные режимы:

- `UziPet.exe --snapshot <папка>` рисует позы и все выражения визора в PNG;
- `UziPet.exe --icons` пишет в `bin\uzipet.log` иконки рабочего стола и окна-платформы;
- `UziPet.exe --icons-move <имя>` сдвигает иконку, читает позицию обратно и возвращает на место;
- `UziPet.exe --web-serve` поднимает её страницу без браузера, адрес в логе;
- `UziPet.exe --web-visit` через 10 секунд отправляет её в браузер, только если расширение на связи.

## Арт

Детали можно вырезать руками: открыть `tools/cuts.html` в браузере, в режиме «Нарезка» обвести каждую деталь
на исходной картинке и поставить ей ось, в режиме «Лицо» обвести визор и подбородок. «Сохранить» кладёт
`uzi_cuts.json` в «Загрузки»; его надо положить в `tools/cuts/` и запустить `python tools/rebuild_rigs.py`,
потом `build.bat`. То, что на картинке закрыто соседними деталями, сборщик дорисует сам.

`assets/atlas.png` и `assets/rig.json` собирает `tools/slice_uzi.py` из `art/uzi_ref.webp`
(подробности и как получить слои от ChatGPT в `ATLAS.md`). Старая заглушка: `tools/make_placeholder.py`.

Фразы лежат в `assets/phrases.json`, их можно править как угодно (`%s` заменяется на имя иконки,
тему и так далее, `{name}` на то, как она тебя зовёт). Подписи кнопок в категориях `choice*`.
