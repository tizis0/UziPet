# UziPet 0.14.7

20 ноября 2026, 13:55 МСК

- В однофайловую сборку Windows x64 включён компактный CPython 3.14.10. UziPet распаковывает его рядом с собой и использует для Python-модов.
- Сборщик проверяет SHA-256 официального пакета Python и сохраняет скачанный архив в кеше.
- Установщик проверяет результат распаковки. Если компонент Python отсутствует, UziPet повторяет распаковку при запуске.
- В README описано обновление через перетаскивание нового EXE на Узи.
